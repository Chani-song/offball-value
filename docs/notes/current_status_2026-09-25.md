# 현재 상황 (2026-09-25)

오프더볼 런 → 반응 수비수 → 수혜자를 7경기 트래킹에서 찾고, 그 장면을 준현님
정확 솔버(mit_ssac2027)로 풀어 수비수의 딜레마를 재는 파이프라인의 현재 상태입니다.
숫자는 모두 이 날짜의 실행 결과입니다. 데이터와 결과물은 저장소에 없습니다(아래 "데이터").

## 1. 파이프라인과 단계별 남는 수

| 단계 | 하는 일 | 남는 수 |
|---|---|---|
| 0 국면 | 공격팀의 안정 점유 구간. 6초 이상, 공격 진영 진입, 공 소유 1.5 m, 상대가 0.32초 이상 잡으면 끊김 | 720 국면 |
| 1 런 시작 | 속도 +1.5 m/s·방향 25°(2 m/s 이상일 때)·1초 안 3 m 이동 등으로 감지 → 상황 조건(공 가진 선수 1.5 m 이내, 러너≠공 가진 선수, 직전 0.5초 안정 점유, 이후 1초 우리 팀 점유) → 안정 점유·주 후보·이미 검토한 장면 제외 | 726 → 639 → 588 런 |
| 2 책임자 | 런마다 반응 수비 후보 1,931쌍 → 쌍 게이트 980쌍 → 주인공 규칙 → 수혜자(R9) | 896 조합 (534 런) |
| 게임 형태 | 수혜자 = 볼 소유자 → 2대1 / 다른 공격수 → 3대1 | 178 / 718 |
| 솔버 입력 | 시작 상태 가능(경기장 안, 속도 상한) → 런 속도 ≥ 3.8 m/s → 삼각형 2 m | 2대1 171 → 101 → **32** · 3대1 709 → 363 → **193** |
| 3 솔버 | 0.6초 × 3턴, 수비가 갈린 장면(가장 유력한 흐름에서 한 번이라도 가장 유력한 선택 < 80%) | 2대1 **12** · 3대1 **18** |

- **쌍 게이트**([pair_plausibility.py](../../src/offball_value/pair_plausibility.py)):
  1순위는 항상 남기고, 나머지는 러너에서 15 m 이내이면서 "이웃"(런 경로가 가장 가까운 후보보다 3 m 넘게 멀지 않음)
  또는 "런이 그에게 온다"(0.3초 반응 후 6 m/s로 3 m 여유를 두고 닿음, 런이 11 m 안에서 끝남)일 때 남깁니다.
  압박수는 런이 그의 뒤로 갈 때만 남깁니다. 규혁 판정 188개와 94% 일치(책임 있다고 한 85명 중 84명 유지).
- **주인공 규칙**: 2초간 볼 소유자 이동이 러너의 1.3배 이상이면서 러너가 골문 쪽으로 2 m도 못 가면 제외합니다.
- **수혜자 R9**([coupled_beneficiary.py](../../src/offball_value/coupled_beneficiary.py)):
  열린 공간 × 그 공간 점유 × 그 순간 그에게 공이 갈 때의 위협을 시간마다 곱해 더합니다.
  규혁 검토 99개 중 맞음 64 · 애매 20 · 틀림 15.
- **삼각형**([filter_stage3_states.py](../../scripts/filter_stage3_states.py)):
  2대1은 볼-러너-수비, 3대1은 수혜자-수비-러너(패서 제외)입니다.
  0 / 0.6 / 1.2 / 1.8초에 게임 밖 선수가 안이나 2 m 이내에 있으면 제외합니다(2 m는 규혁 결정).

## 2. 준현님 솔버에 붙인 방식 (원본은 수정하지 않음)

`andrew/`는 준현님 저장소 그대로(e8b0a95)이고, 변형은 복사본 폴더에만 있습니다.

- [andrew-passer2on1/](../../andrew-passer2on1/DESIGN.md): **2대1**, 볼 소유자 = 수혜자.
  준현님 게임에 다른 수비수들(실제 경로, 결정 없음)을 xPass·오프사이드(뒤에서 두 번째 수비)·xT에 넣었습니다.
  배경이 없으면 원본과 비트 단위로 같음을 테스트했습니다.
- [andrew-fixedpasser/](../../andrew-fixedpasser/DESIGN.md): **3대1**, 패서는 실제 경로로 고정하고
  러너·수혜자·수비만 전략적으로 움직입니다. 패스는 둘 중 최선. 태클 없음, 끝까지 공 보유 없음.
- **이동 모델 "agile"**([agile_motion.py](../../andrew-passer2on1/passer2on1/agile_motion.py), `--physics agile`):
  - 올리기 4.5 / 줄이기 6.0 / 틀기 6.0 m/s²(선수 기준 타원)
  - 급제동 후 꺾기 9.0 m/s² (0.1초 멈춤)
  - 수비 반응 지연 0.2초(시작 때만)
  - 최고 속도 9.0 m/s (2대1 볼 소유자는 7.2)
  - 우리 예전 모델 값(규혁 결정)이고, 준현님 모델은 3.8 하나라 결정이 한 턴 안에 거의 안 보였습니다.
- 결과 화면은 실행 기록(manifest)의 이동 모델로 경로를 다시 계산하고, 저장된 플레이와 어긋나면 에러를 냅니다.

## 3. 패스 모델 후보 (3대1·2대1, 삼각형 2 m 장면)

지금 모델(`experimental_pass.json`)은 StatsBomb 360으로 학습됐고 **위치만** 봅니다.
속도가 없고, 가까운 수비 2명만 보며, 받는 선수–목표 거리에 거의 반응하지 않습니다.

| 모델 | 학습 | 우리 패스 1,561개 AUC / Brier | 뒷공간 스루패스 시험 (정지 → 침투 → 수비 반대로) |
|---|---|---|---|
| 지금 모델 | StatsBomb, 위치만 | 0.815 / 0.118 | 0.89 → 0.89 → 0.89 |
| **A 물리 경주** | 우리 패스, 3개 값 | 0.809 / 0.105 | **0.71 → 0.81 → 0.90** |
| B1 | 준현님 속도 로지스틱, 우리 패스 | 0.832 / 0.099 | 0.10 → 0.11 → 0.11 |
| B1-SB | 같은 로지스틱, StatsBomb 360 5만 개 | 0.828 / 0.100 | 0.85 → 0.80 → 0.79 |

- 우리 패스로 학습한 모델은 **경기별 교차 적용**을 했습니다. M 경기 장면은 M 경기를 뺀 모델로 평가합니다.
- 목표 지점은 킥 순간 공의 방향만으로 정해 누수를 막았고, 킥 시각은 트래킹에서 다시 찾았습니다.
- StatsBomb 360 사진은 **이벤트를 한 팀 기준**이라, 다른 팀 이벤트와 짝지을 때 좌표를 뒤집어야 합니다(측정으로 확인).

솔버에서 러너가 실제로 골문 쪽으로 3 m 넘게 뛴 장면의 수비 반응입니다(실제는 94~96% 물러남).

## 4. 찬의 주석 장면이 어디서 빠지나 (strong 5 + medium 40)

[trace_chani_scenes.py](../../scripts/trace_chani_scenes.py), 장면마다 지목된 선수 중 가장 멀리 간 선수 기준입니다.

| 빠지는 곳 | strong | medium |
|---|---|---|
| 0단계 국면 없음 | 1 | 14 |
| 1단계 감지 규칙 | 0 | 8 |
| 1단계 상황 조건 (대부분 "공 가진 선수 1.5 m 이내") | 2 | 13 |
| 1단계 운영상 제외 (이미 검토 / 안정 점유 아님) | 1 | 4 |
| 솔버 입력 (런 속도 < 3.8) | 0 | 1 |
| 솔버까지 도달 | 1 (J03WPY shot_018 → 2대1 장면) | 0 |

- "공 가진 선수 1.5 m 이내"에 걸린 순간의 공–가장 가까운 선수 거리는 중앙값 3.45 m입니다. **패스가 날아가는 중에 런이 시작**된 경우예요.
- 0단계는 점유가 상대의 짧은 터치로 6초 미만 조각이 되는 경우(11), 슈팅 순간 점유가 없는 경우(4, 세컨드볼·세트피스)입니다.
- 국면 경계는 5프레임 표본 위치에 예민합니다.

## 5. 알려진 문제와 다음 할 일 (2026-09-25 미팅)

- 60장면(찬의 30 + 솔버 30) 평가 도구: 1~5점, 3명 → top 3 / top 5, Figure 1 후보.
- xT가 뒷공간을 충분히 높게 보는지 점검합니다(패스 성공률과 xT를 장면별로 따로 시각화).
- 패스 후보: 100개 규칙 후보 중 성공률×xT top 5, 또는 진행 방향 90° 부채꼴 5등분.
  솔버는 매 상태에서 최선 패스 하나만 쓰므로, 후보 수는 게임 크기가 아니라 계산 시간에 영향을 줍니다.
- 움직임 명령을 선수 기준 방향(볼 쪽, 자기 골문 쪽, 러너 쪽, 유지하며 감속·가속)으로 바꾸는 안.
- 결과와 무관한 선수가 "멈추기"로 표시됩니다(값이 같을 때 첫 선택). 선택별 값을 저장해 "선택 무관"으로 표시할 예정입니다.
- 필터 완화 후보: "공 가진 선수 1.5 m 이내"(찬의 장면 12개), 국면 최소 6초.
- 2대1 장면 2(Zimmermann이 볼 앞): 작은 게임에 다른 선수가 낀 장면은 결과에서 제외합니다.
